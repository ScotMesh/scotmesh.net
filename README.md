# scotmesh.net

Source for [scotmesh.net](https://scotmesh.net/). Static HTML served by nginx, no build step.

Deploy by copying everything except this README and `.git` into the site's web root. Copy over the top rather than mirroring with delete: other sites load `favicon.svg` and the `logo*.png` files straight from scotmesh.net. Those logo files keep their old names and sizes but now carry the new brand.

Brand assets (logo, colours, fonts) come from [ScotMesh/branding](https://github.com/ScotMesh/branding).
