ScotMesh Tools & Services

The live tools and infrastructure behind ScotMesh, for the three networks ScotMesh people run — MeshCore, Meshtastic and Reticulum.

LoRa mesh

MeshCore

Long-range LoRa messaging on cheap radios. These tools show what the Scottish MeshCore mesh is doing, fed by observer radios around the country.

🔭 CoreScopeWhat is on the mesh right now?Nodes, packets and paths as observers see them, updated live. 🗺️ Live MapWhere are the nodes?Every node the observers have heard, on a map of Scotland. 📶 HopReachWhere can I be heard from?Coverage map built from real received packets, not predicted propagation. 🔔 HopReactIs my repeater still up?Alerts when a repeater goes quiet, so you find out before the people relying on it do. 📚 MeshCore wikiHow do I set up and join?Getting started, channels, regions, repeater setup and the FAQ, on the community wiki at scotmesh.uk.

Feeding the tools: running a MeshCore observer

Observers are MeshCore radios that report what they hear to the tools above. If you run one on the MQTT Observer Firmware, point it at ScotMesh with these commands. The hostname is deliberately the long-standing one — every existing observer uses it, and it will keep working.

📡 MQTT endpoint
scotmesh-mqtt.mm7roq.compute.oarc.uk
set mqtt1.preset custom
set mqtt1.server scotmesh-mqtt.mm7roq.compute.oarc.uk
set mqtt1.port 443
set mqtt1.audience scotmesh-mqtt.mm7roq.compute.oarc.uk

Observer firmware: static.loraproject.ie/mqtt. These settings connect your observer to the ScotMesh MQTT infrastructure using MeshCore authentication.

🌊 MeshFlowWhat is the Meshtastic mesh doing?Meshtastic monitor run by a ScotMesh member — nodes and traffic as seen from Scotland. Encrypted network, any bearer

Reticulum

An encrypted network with no accounts and no central authority, carried over LoRa, I2P or plain internet. We run a public transport node anyone can connect to, and the tools to get a radio on it.

📡 Backbone nodeHow do I connect?TCP rns.scotmesh.net:4242 or I2P. Addresses for the chat hub, propagation node and Nomad Network pages. checking… 🔧 ScotMesh FlasherHow do I get a radio or node on it?Step-by-step in your browser: flash an RNode radio, or build a standalone microReticulum node, provision it and set the ScotMesh profile. Firmware is fetched for you. 📚 Reticulum wikiHow does any of this work?Nought to connected, running your own node, the radio settings, and the bugs that have cost us time.
